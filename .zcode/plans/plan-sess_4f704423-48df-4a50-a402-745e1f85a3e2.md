# CatPlan v0.3-alpha：测试补债 + 爱猫人士日常功能

## Context

用户（爱猫人士视角）提出两件事：① 盘点没做过的测试；② 设计下一批实用功能。当前 v0.2.1 的测试缺口：**备份/恢复编解码零自动化测试**（数据安全关键路径）、**提醒通知从未真正弹出过**（核心卖点"不错过"没有端到端证据）、`applyRestore` 合并逻辑、多猫聚合 SQL、CI 缺 lint 和 release 构建。功能侧，代入养猫日常：最常用的动作是**喂食和铲屎**（每天 2-4 次的高频打卡，现有"记喂食"按钮是个占位 stub）、**生日**（数据已有却从不提醒）、通知点了不直达对应页面、以及"连续记录 N 天"还是写死的假数据。

本轮范围（用户已确认全做）：**测试补强包 + 喂食/铲屎打卡 + 生日提醒 + 通知直达 + 真实连续天数**。全部真机验证后才推送；**不打 Release tag**（吸取 v0.2.0 教训：全功能 E2E 完成 + 用户确认后才发版），版本推进为 versionCode 6 / versionName 0.3.0-alpha01。

## 二、新功能实现

**数据层（DB v3→v4）**
- `Entities.kt`：+ `DailyEntity(type: "feed"/"litter", catId: Long?（null=全家）, dateEpochDay, createdAtEpochMs)`
- `CatPlanDao.kt`：+ `DailyDao`（`observeSince(epochDay)`, `insert`）；`CatPlanDatabase` version 4 + `MIGRATION_3_4`（CREATE TABLE dailies + 索引）
- `BackupCodec`：BackupData/encode/decode/`applyRestore` 增加 dailies（catId 重映射，null=全家保持），备份 `schemaVersion` 升 3，decode 向后兼容（optJSONArray）

**纯函数（域层，全部配单测）**
- NEW `domain/CatBirthday.kt`：`nextBirthday(birthday, today): LocalDate` + `daysUntil`（2/29 处理：顺延 2/28）
- NEW `domain/Streak.kt`：`streakDays(recordedDates: List<Long>, today): Int`（去重日期向下连续计数，含今天或从昨天起算）

**AppViewModel**（`AppViewModel.kt`）
- `dailiesToday`/`addDaily(type, catId)`；`streak` StateFlow（combine dailies+weights 的日期集合 → Streak.streakDays）
- 日历/今日任务流合并**生日伪任务**（从 cats 实时推导，不入库：30 天内进日历、3 天内进今日与通知，type="birthday"）

**ReminderWorker**（`worker/ReminderWorker.kt`）
- 通知文案加生日行（`🎂 Mimi 的生日还有 N 天`，用 CatBirthday 对 cats 计算）
- PendingIntent 改为显式 `Intent(context, MainActivity::class.java)` + `FLAG_ACTIVITY_NEW_TASK|FLAG_ACTIVITY_CLEAR_TOP` + `putExtra("open_tab", "today")`

**MainActivity → CatPlanApp**：读取 extra 传 `initialTab`，`CatPlanApp` 用它作 NavHost `startDestination`（remember 固定，旋转不重置）

**TodayScreen**：快捷记录接真功能——记喂食 → 对话框（猫 chips 含「全家」）写入 dailies，chip 显示今日状态（`已喂 ✓`）；铲屎 → 一键打卡即时生效；问候区"连续记录 N 天"接真实 streak

**版本**：versionCode 6 / versionName 0.3.0-alpha01；README 路线图更新（v0.3 进行中 + v0.3 backlog：健康日记模板、换粮七日过渡、粮食库存提醒、桌面小组件、寄养看护单、任务照片存档）

## 三、验证

1. 本地：`gradlew :app:assembleDebug :app:testDebugUnitTest`（预期 23 + 新增 ≈ 35 全绿，含 Robolectric）
2. 真机 E2E（Pixel 6，adb 驱动）：
